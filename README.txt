Pradeep Electronic Store

How to run: unzip, then double-click index.html (any modern browser).
Files: index.html (layout), style.css (styling), script.js (pages, data, charts).
Pages: Dashboard, Products, Orders, Customers, Inventory, Analytics, Suppliers, Settings.
To edit sample data, open script.js and change the arrays P, O, C and S near the top.
